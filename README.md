# Patapon Photo

GitHub Pages용 정적 사진 사이트 초기본입니다.
최종 사이트 주소: https://pataponphoto.github.io/

원본 MD와 생성 코드는 https://github.com/pataponphoto/cosplay-collage 에 있습니다.
이 저장소에는 build_site.py로 생성한 HTML/CSS/JS가 들어 있습니다.
Patapon_Photo 프로필의 게시글 56개와 사진 119개를 연결했습니다.
목록은 긴 변 640px 썸네일, 상세는 최대 1280px WebP를 사용합니다.
사진은 media 폴더에서 직접 제공하며 원문과 원 게시자 크레딧을 보존합니다.

현재는 비공개 준비본이며 GitHub Pages 배포는 활성화하지 않았습니다.
원문에서 확인되지 않는 모델·행사·촬영일은 소스 저장소에서 보완할 수 있습니다.
MYBOX 자동 연결과 정기 동기화는 구성하지 않았습니다.

배포할 때 GitHub Pages의 게시 소스를 main 브랜치의 /(root)로 설정합니다.
무료 계정에서 GitHub Pages를 쓰려면 이 사이트 저장소를 공개로 전환해야 합니다.
